# 0001 — Stack: Vite, React, TypeScript and Tailwind v4

- **Date:** 2026-10-13
- **Status:** accepted

## Context
The guide started as an HTML page generated by a script. To refine the interface and maintain 21 builds, we need
reusable components, types for the data and a design system applied consistently.

## Decision
- **Vite 6 + React 18 + strict TypeScript.** Static build, no server.
- **Tailwind CSS v4** with `@tailwindcss/vite`. Tokens defined in `@theme` in `src/styles.css`, with the default
  palette turned off (`--color-*: initial`), so that only the Logbook colors exist.
- Hash-based routing (`#/id`), no routing library.
- Pinned versions (no `^`) in `package.json`.

## Consequences
- A new token automatically becomes a new utility (`bg-<token>`, `text-<token>`).
- There is no "escape hatch" through `bg-slate-800`; a new color requires a token and an entry in the design system.
- Deploying on Vercel works with no extra configuration.
